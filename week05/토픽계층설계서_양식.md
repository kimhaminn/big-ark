## 1. 소비 계통 — 먼저 센다

**토픽을 가르기 전에 누가 읽을지부터 센다.** 가를 이유는 소비 쪽에서 생긴다.

| # | 소비 계통 | 무엇을 걸러야 하는가 |
|---|---|---|
| ① | | |
| ② | | |
| ③ | | |

> TFDS-Edu 는 원시 토픽에 **3계통**이 붙는다 (경량 처리 · 시계열 적재 · 원본 아카이브).
> **셋이 각각 무엇만 받으면 되는지**를 적는다. 「전부」라고 적어도 되지만 **왜 전부인지**는 적는다.

## 2. 축과 순서 ★채점 대상

**후보 축을 다 적고, 쓸 것에 순서를 매긴다.**

| 축 | 값의 예 | 몇 번째에 두는가 | ★ 근거 — 왜 그 자리인가 |
|---|---|---|---|
| 현장(터널) | `t01` `t02` | | |
| 구역 | | | |
| 장비(리피터) | | | |
| 센서 종류 | `temp` `smoke` | | |
| 데이터 성격 | `raw` `verdict` | | |
| | | | |

**최종 토픽 형태**

```
                                        ← 여기에 적는다 (예: tfds/{현장}/{센서종류})
```

> **근거 열이 비면 미완성이다.** 「이게 자연스러워서」는 근거가 아니다.
> **§1 의 소비 계통 중 어느 것이 그 축을 필요로 하는가**를 가리키면 근거가 된다.

## 3. 구독 문장 3개 ★채점 대상

**축 순서의 결과가 여기서 보인다.** `+` 와 `#` 를 실제로 써서 적는다.

| # | 무엇을 받고 싶은가 | 구독 문장 | 이 순서라서 가능한가 |
|---|---|---|---|
| ① | | | ○ / △ / × |
| ② | | | ○ / △ / × |
| ③ | | | ○ / △ / × |

> ★ **하나쯤은 `×` 나 `△` 가 나오는 것이 정상이다.** 모든 축을 앞에 둘 수는 없다.
> **`×` 가 나온 것을 지우지 않는다** — 그것이 §5 에 그대로 들어간다.
