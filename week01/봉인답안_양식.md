# 봉인 답안 — 오늘 가장 모르겠는 것

> **1주차 실습 P4** · 이 파일을 자기 리포지토리에 복사해 채운다.
> ★ **채운 뒤에는 12주차까지 열지 않는다.**

---

## 무엇을 적는가

조감 노트의 칸 중에서 **지금 가장 이해가 안 되는 칸**을 **하나만** 고른다. 그리고 그 칸에 대해 **무엇이 궁금한지** 한 줄로 적는다.

"다 모르겠다"가 정상이다. 그중에서 **가장** 모르겠는 하나를 지목하는 것이 오늘 할 일이다.

---

## 답안

**내가 고른 칸**

```
(칸 이름 하나)
```

**무엇이 궁금한가 (한 줄)**

```
(한 줄 — "왜 여기에 이게 필요한지 모르겠다" 정도면 충분하다)
```

**적은 날짜**

```
(YYYY-MM-DD)
```

---

## 채점하지 않는 것

- **질문의 수준을 보지 않는다.** 아직 도구를 하나도 배우지 않았으므로 날카로운 질문이 나올 수 없고, 나올 필요도 없다
- 검수는 **칸 1개와 궁금한 것 1줄이 적혀 있는가**까지다

## 12주차에 하는 일

이 파일을 열어 **그때의 질문에 지금의 내가 답해 본다.** 답할 수 있으면 이 과정이 한 일이 그것이다. 여전히 답이 안 되는 부분이 있다면 그것이 다음에 배울 것이다.

> **모른다는 것은 지금 확실히 아는 유일한 것이다.** 12주 뒤에는 무엇을 몰랐는지조차 기억나지 않으므로, 오늘 적어 두지 않으면 자신이 얼마나 왔는지 잴 기준이 없어진다.
